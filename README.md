# ASTRA Pocket Auto

نسخة تأسيسية لتطبيق Android باسم ASTRA Pocket Auto.

## الموجود في هذه النسخة
- مشروع Android/Kotlin أساسي.
- واجهة عربية بسيطة.
- طلب إذن الظهور فوق التطبيقات.
- نافذة عائمة صغيرة قابلة للسحب.
- أزرار تشغيل وإيقاف النافذة.
- إشعار foreground أثناء تشغيل خدمة النافذة.

## غير الموجود بعد
- لا يوجد اتصال بـ Pocket Option.
- لا يوجد التقاط شاشة أو تحليل شموع.
- لا توجد استراتيجية تداول أو إدارة صفقات.
- لا يتم إرسال أو تنفيذ أوامر تداول.
- زر "اختبار الواجهة" يغيّر حالة العرض فقط.

## متطلبات البناء
- Android Studio حديث.
- JDK 17.
- Android SDK 35.
- Gradle 8.7 أو أحدث متوافق مع Android Gradle Plugin 8.6.1.

افتح المستودع كمشروع Gradle في Android Studio ثم نفّذ Sync وBuild APK.

## مراحل التطوير المقترحة
1. بناء التطبيق والتحقق من عمل النافذة العائمة على الجهاز.
2. إضافة التقاط الشاشة عبر MediaProjection بموافقة المستخدم.
3. بناء قارئ بصري للشارت مع معايرة يدوية واختبارات Replay.
4. إضافة Paper Trading وسجل نتائج واختبارات مخاطر.
5. التحقق من شروط المنصة وأي واجهة تنفيذ رسمية قبل التفكير في أي تنفيذ حقيقي.

لا تستخدم هذه النسخة للتداول الحقيقي؛ فهي واجهة أولية فقط.
