# ASTRA Pocket Auto

نسخة تأسيسية لتطبيق Android باسم ASTRA Pocket Auto.

## ما تم تنفيذه
- مشروع Android/Kotlin أساسي.
- واجهة عربية لبدء وإيقاف مشاركة الشاشة.
- نافذة عائمة صغيرة قابلة للسحب.
- التقاط الشاشة عبر Android MediaProjection بعد موافقة المستخدم.
- قراءة إطارات RGBA محليًا عبر ImageReader.
- معدل معالجة مستهدف 15 إطارًا/ثانية (فاصل أدنى يقارب 66.7ms).
- محلل بصري هجين أولي: شبكة عينات من المنطقة الوسطى + مقارنة التغير بين الإطارات المتتابعة.
- إرسال حالة الحركة وعدد الإطارات إلى النافذة العائمة.

## حدود التحليل الحالي — مهم
المحلل الحالي يقيس **التغير البصري العام** في منطقة وسط الشاشة فقط. لا يحدد حدود الشموع أو أسعارها، ولا يميز CALL/PUT، ولا ينتج إشارة تداول. منطقة التحليل ليست معايرة على مخطط Pocket Option بعد. معدل 15 FPS مستهدف وقد ينخفض حسب أداء الهاتف وحرارة الجهاز وحجم الشاشة.

## ما لم يتم تنفيذه
- لا يوجد اتصال برمجي بـ Pocket Option.
- لا يوجد استخراج موثوق لبيانات OHLC أو أسعار السوق.
- لا توجد استراتيجية تداول أو إدارة صفقات مكتملة.
- لا يتم إرسال أو تنفيذ أوامر تداول.
- لا توجد نتائج اختبار أداء فعلية على جهاز المستخدم حتى الآن.

## طريقة التجربة الأولية
1. ابنِ التطبيق وثبّته على جهاز Android.
2. افتح ASTRA وامنحه إذن الظهور فوق التطبيقات.
3. شغّل النافذة العائمة.
4. اضغط "بدء بث الشاشة والتحليل" ووافق على نافذة Android لمشاركة الشاشة.
5. افتح شاشة الشارت. ستعرض النافذة حالة التغير البصري وعدد الإطارات التي تمت معالجتها.
6. أوقف الالتقاط من داخل التطبيق عند الانتهاء.

## متطلبات البناء
- Android Studio حديث.
- JDK 17.
- Android SDK 35.
- Android Gradle Plugin 8.6.1 مع Gradle 8.7 متوافق.

افتح المستودع كمشروع Gradle في Android Studio ثم نفّذ Sync وBuild APK.

## مراحل التطوير التالية
1. بناء APK وفحص أخطاء Gradle/Kotlin على بيئة بناء فعلية.
2. إضافة معايرة يدوية لمنطقة الشارت واستبعاد عناصر واجهة التطبيق.
3. تطوير كشف الشموع والاتجاه والحركة مع اختبارات على تسجيلات شاشة.
4. إضافة Paper Trading وسجل نتائج واختبارات مخاطر.
5. التحقق من شروط المنصة وأي واجهة تنفيذ رسمية قبل التفكير في أي تنفيذ حقيقي.

لا تستخدم هذه النسخة للتداول الحقيقي؛ إنها مرحلة التقاط شاشة وقياس حركة بصرية فقط.
